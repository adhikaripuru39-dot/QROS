# The QROS Code of Scientific Conduct

**Ratified founding. Faithful transcription.** This code governs how research is performed.

### Principle 1
Every claim requires evidence.

### Principle 2
Every hypothesis must be falsifiable. If it cannot be tested in a way that could prove it wrong, it is not suitable for scientific investigation.

### Principle 3
Every dataset must be validated. Before analysis: Check completeness · Handle missing values · Verify timestamps · Detect duplicates · Assess quality · Record data provenance.

### Principle 4
Every experiment must be documented. A minimum experiment record includes: Objective, Hypothesis, Data source, Methodology, Parameters, Results, Interpretation, Limitations, Next actions.

### Principle 5
Negative results are valuable. Recording unsuccessful experiments prevents repeated mistakes and expands institutional knowledge.

### Principle 6
Avoid confirmation bias. Researchers should actively seek evidence that challenges their own hypotheses.

### Principle 7
Separate research from opinion. Personal conviction does not replace statistical evidence.

### Principle 8
Production requires independent validation. No strategy should move into production without completing the documented review and validation process.

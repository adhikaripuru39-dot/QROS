# QROS - Stage 2 Scope Package

## Stage 2 objective
Define the approved data foundation for QROS.

## In scope
- Data collection boundaries
- Canonical source list
- Data provenance and lineage rules
- Schema and identifier conventions
- Timestamp and timezone conventions
- Data quality rules for completeness, consistency, freshness, and traceability
- Input/output contract specifications for Parts 1-3

## Out of scope
- Strategy logic
- Feature engineering implementation
- Hypothesis generation or registration
- Research execution
- Backtesting
- Live trading
- Execution or risk automation

## Inputs
- Stage 1 governance artifacts
- Constitution
- Founding Governance Documents
- Handbook Parts 1-3

## Outputs
- Stage 2 data-contract specification
- Stage 2 validation checklist
- Data-domain boundary map
- Decision log entry for approval or revision

## Exit condition
The data foundation is approved as a specification-only baseline and can be handed to later stages for controlled implementation.

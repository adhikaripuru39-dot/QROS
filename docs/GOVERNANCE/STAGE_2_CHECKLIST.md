# QROS - Stage 2 Compliance Checklist

Run this before any Stage 2 task.

## G0 - Do not proceed
Before the data scope, inputs, outputs, and validation rules are approved, the following are forbidden:

- [ ] Do not build or modify any engine, module, strategy, backtest, or execution code.
- [ ] Do not create hypothesis artifacts or edge claims.
- [ ] Do not run research experiments or walk-forward tests.
- [ ] Do not freeze a dataset for experimentation without approved Stage 2 data rules.
- [ ] Do not claim ratification, approval, or production readiness.

## Pre-task
- [ ] Task is limited to Parts 1-3 data foundation work.
- [ ] Source governing sections are cited.
- [ ] Scope, inputs, outputs, and validation requirements are explicitly documented.
- [ ] Constitution is still treated as draft governance.

## During-task
- [ ] No prohibited work executed.
- [ ] Any data rule or threshold is traceable to a governing source.
- [ ] No retroactive adjustment of criteria to force a pass.
- [ ] No implementation artifact is created unless it is purely a specification document.

## Post-task
- [ ] Outputs match the charter and are traceable.
- [ ] No approval or production claims are made.
- [ ] Decision log updated with the Stage 2 result.
